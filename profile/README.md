# Lutech‑Siad

Organization GitHub del team **SIAD** (Lutech Group).

## Progetti

| Repository | Descrizione |
|---|---|
| `nexusq-backend` | Backend .NET — API e logica di business |
| `nexusq-frontend` | Frontend Angular — SPA |
| `nexusq-jobs` | Quartz / servizi batch (.NET) |
| `nexusq-infrastructure` | CI/CD, documentazione, policy e agenti |
| `nexusq-translations` | Risorse multilingua |

## Processo

- **GitFlow**: `main` + `develop`, conventional commits, squash merge su main
- **Code review** obbligatoria su ogni PR
- **Security-first**: Dependabot attivo, branch protection via org rulesets
- **AI-assisted**: GitHub Copilot integrato nel workflow
